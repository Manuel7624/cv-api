Cómo está hecha esta web

La he programado yo desde cero. Por dentro es una API hecha con Python y FastAPI que guarda mi información en una base de datos. Cuando preguntas algo, el chat busca primero los datos sobre mí que tienen que ver con tu pregunta y responde solo con ellos, para no inventarse cosas. Si un proveedor de IA falla, pasa automáticamente a otro. Todo funciona en Docker y está comprobado con tests automáticos.
